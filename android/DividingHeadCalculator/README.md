# Делительная головка — Калькулятор

Android-приложение (Kotlin + Jetpack Compose, MVVM) для расчёта настроек универсальной
делительной головки (УДГ) на фрезерном станке. Работает полностью офлайн, без интернета
и без бэкенда.

Поддерживаются все три вида деления:

1. **Простое (прямое) деление** — `I = N / n`, подбор круга отверстий делительного диска,
   расчёт погрешности в угловых секундах/минутах и в % от шага.
2. **Дифференциальное деление** — автоподбор вспомогательного числа `n'`, расчёт сменных
   шестерён гитары `i = N(n' - n)/n'`, определение направления вращения делительного диска.
3. **Винтовое (спиральное) деление** — расчёт передаточного отношения гитары
   `i = (N · Pв) / T`, подбор шестерён, расчёт угла поворота стола и погрешности шага спирали.

### Расчётное ядро (`calc`)

Модуль `calc` — чистый Kotlin без зависимостей от Android SDK, поэтому его юнит-тесты
выполняются за секунды и без эмулятора. В нём находятся:

- `SimpleIndexing` — простое деление;
- `DifferentialIndexing` — дифференциальное деление (подбор `n'`, направление вращения);
- `HelicalIndexing` — винтовое деление (гитара, угол поворота стола, ошибка шага);
- `GearCombinationSearch` — полный перебор одинарных и составных (двухпарных) комбинаций
  шестерён гитары с проверкой на "паразитную" коллизию шестерён на общей оси;
- `Fraction` — точная рациональная арифметика (без ошибок округления при проверке "точное
  ли деление");
- `model/Presets` — встроенные пресеты: Brown & Sharpe (дюймовый), УДГ-135/УДГ-160
  (метрический).

Тесты покрывают все три вида деления и краевые случаи: `n = 1`, очень большие `n`,
отсутствие точного решения в пределах комплекта дисков/шестерён, пустой/минимальный
набор шестерён.

### Приложение (`app`)

- **Jetpack Compose + Material 3**, тёмная/светлая/системная тема, опция
  "увеличенный шрифт для цеха".
- **MVVM + StateFlow** — по одному ViewModel на каждый экран расчёта, плюс общие
  ViewModel для настроек и пресетов.
- **Room** — история расчётов и пользовательские пресеты (круги, шестерни, характеристика
  головки, шаг ходового винта) — всё редактируемо, можно создать свой пресет.
- **DataStore** — последний выбранный пресет, тема, единицы измерения, режим крупного
  шрифта — сохраняются между запусками.
- Экран результата показывает: что крутить (обороты + отверстия + круг), схему
  делительного диска с подсвеченным сектором (Compose Canvas), схему гитары шестерён
  с подписанными числами зубьев, и блок "Точность" (зелёная/жёлтая-красная отметка,
  кнопка "показать другие варианты").
- Без сетевых разрешений — приложение не запрашивает доступ в интернет.

## Как пользоваться

1. Откройте приложение — на стартовом экране три карточки: «Простое деление»,
   «Дифференциальное деление», «Винтовое деление».
2. При необходимости зайдите в **Настройки головки** (значок шестерёнки) — выберите
   пресет (УДГ-135/160, Brown & Sharpe) или создайте свой (характеристика N, круги
   отверстий, шестерни гитары, шаг ходового винта). Там же — тема оформления, крупный
   шрифт для цеха, единицы измерения.
3. На экране расчёта введите нужные параметры (число делений `n`, либо шаг спирали
   `T` и диаметр заготовки) и нажмите «Рассчитать».
4. Результат показывает, что крутить, схему и блок точности. Если решение не точное —
   можно посмотреть другие варианты гитары в списке ниже.
5. Все расчёты автоматически сохраняются в **Историю** (значок часов на стартовом
   экране) — чтобы не пересчитывать одно и то же в следующий раз.

## Как пересобрать проект

Требуется JDK 17+ (в проекте используется байт-код уровня 17) и доступ к Android SDK.
Gradle Wrapper уже включён в проект — устанавливать Gradle отдельно не нужно.

```bash
cd android/DividingHeadCalculator

# указать путь к Android SDK (или установить переменную окружения ANDROID_HOME)
echo "sdk.dir=/путь/к/android-sdk" > local.properties

# юнит-тесты расчётного ядра
./gradlew :calc:test

# сборка debug APK (подписан отладочным ключом автоматически)
./gradlew assembleDebug
# результат: app/build/outputs/apk/debug/app-debug.apk

# сборка release APK
./gradlew assembleRelease
# результат: app/build/outputs/apk/release/app-release.apk
```

Если в каталоге `keystore/` лежат `release.keystore` и `keystore.properties`, release-сборка
подписывается ими автоматически (см. `app/build.gradle.kts`); без них release APK собирается
неподписанным. Оба файла в `.gitignore` — пароли никогда не попадают в репозиторий.

Чтобы создать свой ключ:

```bash
keytool -genkeypair -v -keystore keystore/release.keystore -alias dividinghead \
  -keyalg RSA -keysize 2048 -validity 10000
```

и положить рядом `keystore/keystore.properties`:

```properties
storeFile=release.keystore
storePassword=<пароль хранилища>
keyAlias=dividinghead
keyPassword=<пароль ключа>
```

**Важно:** этот файл ключа нужен для подписи *каждого* последующего обновления
приложения в RuStore/Google Play — если его потерять, обновить уже опубликованное
приложение будет невозможно (только публикация под новым именем пакета). Храните
`release.keystore` и пароли из `keystore.properties` в надёжном месте (менеджер
паролей, зашифрованный бэкап) отдельно от репозитория.
