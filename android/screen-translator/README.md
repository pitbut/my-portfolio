# Экранный переводчик (Android)

Переводит текст на экране **любого** приложения автоматически, прямо поверх оригинала.
Работает и в Telegram, включая каналы и чаты с «запретом копирования».

## Как пользоваться

1. Установите `ScreenTranslator.apk` (раздел **Releases** → `screen-translator-latest`).
2. Откройте приложение → «Открыть Специальные возможности» → включите «Экранный переводчик».
   - Android 13+: если переключатель серый — «О приложении» → ⋮ → **«Разрешить ограниченные настройки»**.
3. Выберите язык перевода и нажмите «Скачать языковые модели» (один раз, ~30 МБ на язык).
4. Откройте любое приложение — поверх текста появятся плашки с переводом.

### Плавающая кнопка
| Действие | Что делает |
|---|---|
| Нажатие | **Оригинал** ↔ перевод (кнопка показывает `ОРИГ` или код языка, например `RU`) |
| Удержание | Меню: оригинал, перевод с картинки (OCR), пауза, «не переводить в этом приложении», настройки |
| Перетаскивание | Переместить кнопку; она прилипает к краю экрана |

## Как это устроено

- **Чтение текста — `AccessibilityService`.** Служба получает дерево элементов экрана, как TalkBack.
  Telegram в чатах с запретом копирования прячет кнопки «Копировать/Переслать/Перевести» и
  запрещает скриншоты (`FLAG_SECURE`), но текст сообщений службам спец. возможностей отдаёт
  (иначе незрячие не смогли бы читать). Поэтому перевод там работает.
- **Перевод — Google ML Kit на устройстве.** Язык каждой фразы определяется автоматически,
  модели скачиваются один раз, дальше работает офлайн; переписки никуда не отправляются.
- **Отрисовка — окна `TYPE_ACCESSIBILITY_OVERLAY`.** Им не нужно разрешение «поверх других
  приложений», и они пропускают касания, так что приложение под переводом работает как обычно.
  Плашки прячутся при прокрутке и появляются снова, когда экран остановится. Поля ввода,
  клавиатура и системные панели не закрываются.
- **OCR (Android 11+).** Для текста на картинках, в видео и играх — снимок экрана силами службы
  (`takeScreenshot`) + ML Kit Text Recognition (латиница, китайский, японский, корейский).
  Окна с `FLAG_SECURE` (банки, секретные чаты) система не даёт снять — там работает только
  обычный текстовый перевод.

## Сборка

```bash
cd android/screen-translator
./gradlew assembleRelease   # app/build/outputs/apk/release/app-release.apk
```

APK подписан ключом из `keystore/` (пароль `screentranslator`), чтобы новые сборки
ставились поверх старых. Ключ публичный — для магазина приложений сделайте свой.
