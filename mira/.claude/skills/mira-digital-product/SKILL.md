# Mira — digital product

Brand rules from **mira-base-character**: evidence-based, no hype, no medical treatment. Promotion content via **mira-content-engine**.

## Product types (from easiest)
1. **Free lead magnet** — 1-page checklist ("10 привычек для сна с доказательностью 4–5"). Goal: followers → Telegram channel / email.
2. **Mini-guide PDF** 10–20 pages — one topic (сон, вода, движение за столом). Price idea: $3–7.
3. **7-day challenge** — daily card + short video + tracker. Price idea: $5–10.
4. **30-day habit program** — weekly modules, tracker, community chat. Price idea: $15–30.
5. **Printable/digital tracker** (sleep, water, steps) — sheet or PDF.

## Structure for any guide / challenge
1. Cover with Mira (scene still) + title + promise (realistic, measurable).
2. "Как пользоваться" + disclaimer: "Это не медицинская консультация. При заболеваниях — к врачу."
3. Evidence legend: what 1–5 means.
4. Content blocks: each habit = what · why (evidence score + source to verify) · how to start today · common mistake.
5. Tracker page.
6. Final page: next step (next product / channel link).

## Workflow
1. Ask: topic, format, language (RU/UZ/EN), price level, where it will be sold (Telegram, Gumroad, Payhip, own site robutpit.com).
2. Propose outline → user approves.
3. Draft full content (as a doc; export to PDF/Word if needed).
4. Generate cover and inner images with **mira-scene-still**.
5. Write 3 launch posts + 1 talking-scene script with **mira-content-engine**.

## Hard rules
- No promises of cures, weight numbers, medication or supplement advice.
- Never invent studies — list sources as "проверить" for the user to confirm.
- Refund/support line and "AI-created character" disclosure on the sales page.
