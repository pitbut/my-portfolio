# Эскиз — обмер деталей по фото

Android-приложение для конструктора: снимаете деталь, приложение находит контур и отверстия,
вы вводите размеры, которые смогли замерить, — остальные считаются автоматически.
Результат — чистый чертёж на листе A4 со штампом, который можно отправить в Telegram (PNG/PDF)
или открыть в КОМПАС / AutoCAD / nanoCAD / FreeCAD (DXF).

## Что умеет (версия 1.1)

- **Фото** с камеры или из галереи, проекты хранятся на телефоне.
- **Автоконтур**: коснитесь детали или обведите её рамкой — найдутся контур, отверстия и вырезы.
  Вершины притягиваются к углам, отверстия уточняются с субпиксельной точностью.
- **Ручная разметка**: точки (с лупой и привязкой к углам), линии, отверстия по 3 точкам.
- **Правка контура**: удалили точку — её соседи соединяются линией; инструмент «Точка» по линии
  вставляет в неё новую вершину (потом её можно перетащить).
- **Дуги по трём точкам** (инструмент «Дуга»): начало, точка на дуге, конец — или коснитесь линии
  и укажите, через какую точку она должна выгнуться. Радиус ставится на чертеже (R…), известный
  радиус участвует в калибровке.
- **Калибровка по всем введённым размерам сразу**: от одного размера (масштаб) до полной
  перспективы (6+ размеров с диагоналями) — можно снимать под углом.
  - У каждого вычисленного размера честная погрешность (±): если введены только стороны без
    диагоналей, форма не определена и приложение это покажет.
  - Размер, который не сходится с остальными (опечатка, не то ребро), подсвечивается красным
    с подсказкой «по остальным получается …».
- **Лист-мишень A4** (меню на главном экране): распечатайте, положите деталь на него — калибровка
  получается сразу, без ввода размеров.
- **Размеры без наложений**: размеры выносятся за контур, короткие ближе, длинные дальше, цепочки
  на одной линии, текст по ГОСТ 2.307 (вертикальные — снизу вверх). Пошаговый показ размеров.
- **Чертёж**: лист A4 с рамкой и штампом, масштаб по ГОСТ 2.302 выбирается сам, осевые у отверстий.
  Служебные диагонали на чертёж не выносятся (переключатель «На чертеже» у каждого размера).
- **Экспорт** — «Сохранить в файл» (в Загрузки или любую папку) или «Отправить» (Telegram и др.):
  - чертёж PNG, JPG, PDF, SVG (вектор);
  - DXF (R12, мм, слои CONTOUR/AXIS/DIM, дуги — ARC);
  - фото с размерами;
  - **3D-модель STEP**: контур с дугами, вырезами и отверстиями, выдавленный на толщину детали
    (твердотельная модель, открывается в КОМПАС, SolidWorks, FreeCAD, Fusion), с предпросмотром;
  - проект целиком (`.eskiz`: фото + разметка) — открывается на другом телефоне через меню
    «Открыть проект»;
  - всё сразу (при сохранении — одним ZIP).

## Установка на телефон

1. Скопируйте `Eskiz-1.0.apk` на телефон (или откройте из Telegram).
2. Откройте файл и разрешите установку из этого источника.

Нужен Android 8.0 или новее. Разрешения не запрашиваются: фото делается штатной камерой.

## Как пользоваться

1. Снимите деталь как можно ровнее сверху, лучше на контрастном фоне (или на листе-мишени).
2. Инструмент **Авто** — коснитесь детали или обведите её рамкой.
3. Инструмент **Размер** — коснитесь линии контура или двух точек и введите намеренное значение.
   Вводите все размеры, какие смогли замерить, **обязательно 1–2 диагонали**.
4. Синие размеры со знаком ≈ вычислены сами. Красные — не сходятся с остальными, проверьте.
5. Кнопка чертежа вверху — чистый чертёж. **Поделиться** — PNG / PDF / DXF.

Точность: всё, что измеряется, должно лежать в одной плоскости (плоскости, в которой введены
размеры). Выступы над ней и углубления будут с ошибкой. Для листа-мишени: деталь лежит на листе,
поэтому её верхняя плоскость выше листа на толщину — введите пару размеров, калибровка уточнится.

## Сборка своими силами (без GitHub)

Нужен ПК с [Android Studio](https://developer.android.com/studio).

1. Откройте папку `eskiz-android` в Android Studio (File → Open).
2. Дождитесь синхронизации Gradle.
3. Build → Build App Bundle(s) / APK(s) → Build APK(s).

Или из командной строки (нужны JDK 17+ и Android SDK, путь в `local.properties`: `sdk.dir=...`):

```
./gradlew assembleRelease        # APK: app/build/outputs/apk/release/app-release.apk
./gradlew testDebugUnitTest      # тесты калибровки, раскладки и отрисовки
```

## Публикация в RuStore

RuStore требует, чтобы все версии были подписаны **одним и тем же вашим ключом**. Ключ создаётся
один раз и хранится у вас (потеряете — не сможете выпускать обновления).

1. Создайте ключ:
   ```
   keytool -genkeypair -v -keystore eskiz-release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias eskiz
   ```
2. Положите `eskiz-release.jks` в папку `eskiz-android` и создайте рядом файл `keystore.properties`:
   ```
   storeFile=eskiz-release.jks
   storePassword=ваш_пароль
   keyAlias=eskiz
   keyPassword=ваш_пароль
   ```
   Оба файла в `.gitignore` и в репозиторий не попадут.
3. Соберите: `./gradlew assembleRelease` — APK будет подписан вашим ключом.
   Без `keystore.properties` релиз подписывается отладочным ключом (годится только для установки себе).
4. В [консоли RuStore](https://console.rustore.ru) зарегистрируйтесь как разработчик (физлицо,
   самозанятый или ИП), создайте приложение, загрузите APK, иконку, 2–3 скриншота, описание и ссылку
   на политику конфиденциальности (приложение ничего не отправляет в сеть: фото и проекты хранятся
   только на телефоне, передаются только по кнопке «Поделиться»).
5. Для обновлений увеличивайте `versionCode` в `app/build.gradle.kts`.

## Устройство кода

```
app/src/main/java/ru/konstruktor/eskiz/
  geom/      геометрия: калибровка (гомография по известным размерам, ковариация, поиск ошибок),
             раскладка размеров без наложений
  cv/        OpenCV: автоконтур (GrabCut), отверстия (Canny + эллипсы + уточнение по лучам),
             углы для привязки, лист-мишень (ArUco)
  render/    отрисовка фото с разметкой и листа чертежа со штампом
  export/    PNG, PDF, DXF, лист-мишень, «Поделиться»
  data/      модель проекта и хранение
  ui/        экраны (Jetpack Compose)
```
