**Полное описание:**

💰 Как стать миллиардером — увлекательный квест, в котором нужно собирать
пазлы, отвечать на вопросы и искать спрятанные буквы, чтобы составить
финальный пароль и найти клад!

🎮 Как играть:
1. Собери пазл из перемешанных частей фотографии
2. Нажми на красную метку на собранном изображении
3. Введи букву, цифру или слово, спрятанное в этом месте
4. Повтори для всех уровней квеста
5. Собери финальный пароль из найденных букв
6. Найди сокровище!

✨ Возможности:
✓ Готовый демо-квест для быстрого старта
✓ Собственный редактор — создавайте квесты из своих фотографий
✓ Вопросы и задания для каждого уровня
✓ Защита квеста паролем и секретным вопросом
✓ Импорт и экспорт квестов в формате JSON — делитесь с друзьями
✓ Полностью на русском и английском языках
✓ Работает без интернета — все данные хранятся только на вашем устройстве
✓ Никакой рекламы и сбора данных

Отлично подходит для семейных квестов, дней рождения, поиска сокровищ на
даче или обучающих игр с детьми — просто сфотографируйте нужные места и
создайте свой уникальный квест.

**Категория:** Игры → Головоломки / Настольные

## English

**Title:** Millionaire Quest

**Short description (up to 80 characters):**
A puzzle quest with questions and hidden letters. Create your own quests!

**Full description:**

💰 Millionaire Quest is an exciting puzzle adventure where you assemble
puzzles, answer questions, and find hidden letters to compose the final
password and uncover the treasure!

🎮 How to play:
1. Assemble a puzzle from shuffled pieces of a photo
2. Tap the red marker on the completed image
3. Enter the letter, number, or word hidden at that spot
4. Repeat for every level of the quest
5. Compose the final password from the letters you found
6. Find the treasure!

✨ Features:
✓ A ready-made demo quest to get started instantly
✓ A built-in editor — create quests from your own photos
✓ Optional questions/tasks for every level
✓ Password + secret-question protection for your quests
✓ Import/export quests as JSON — share them with friends
✓ Fully available in Russian and English
✓ Works fully offline — everything is stored only on your device
✓ No ads, no data collection

Great for family quests, birthday parties, backyard treasure hunts, or
educational games with kids — just photograph the spots you want and build
your own unique quest.

**Category:** Games → Puzzle / Board
**Content rating:** Everyone
**Keywords:** quest, puzzle, treasure hunt, find the letter, party game, family game
