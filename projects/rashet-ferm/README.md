# Расчёт фермы (сопромат) — модуль для сайта

Плоская стержневая ферма: узлы (координаты), стержни, до нужного числа
опор (шарнир-неподвижный, каток по горизонтали/вертикали), узловые
нагрузки Fx/Fy. Считает статически ОПРЕДЕЛИМЫЕ и НЕОПРЕДЕЛИМЫЕ фермы
одним методом (МКЭ / метод перемещений — стержневой элемент с осевой
жёсткостью EA/L), эквивалентно методу вырезания узлов. Формирует
расчётно-пояснительную записку в .docx: задание, проверка статической
определимости (m + r = 2n), опорные реакции, усилия в стержнях,
геометрия сечения, проверка прочности растянутых и устойчивости
сжатых стержней (формула Эйлера), рисунки схемы и усилий.

## Файлы
- `truss_engine.py` — ядро: МКЭ-решатель фермы, определимость, усилия.
- `sections.py` — геометрия сечений (те же формы, что у калькулятора балки,
  плюс `min_moment_of_inertia` для проверки устойчивости).
- `diagrams.py` — расчётная схема и диаграмма усилий (matplotlib).
- `report.py` — сборка .docx записки.
- `app.py` — Flask: `/`, `/api/calculate`, `/api/report`.
- `templates/index.html`, `static/app.js`, `static/style.css` — интерфейс:
  узлы/стержни/опоры/нагрузки + быстрый шаблон "ферма Пратта".
- `demo.py` — автономный пример без Flask.

## Проверено на
- 3-стержневая треугольная ферма — усилия совпали с ручным расчётом
  методом узлов (растяжение нижнего пояса, сжатие раскосов) ✓
- ферма с избыточной диагональю (статически неопределима) — решена без
  ошибок, равновесие ΣFx=ΣFy=0 подтверждено ✓
- симметричная 8-узловая ферма с 3 узловыми нагрузками — реакции
  симметричны и равны половине суммарной нагрузки, как и должно быть ✓

## Запуск локально
```
pip install -r requirements.txt
python app.py
```
## Деплой
Аналогично калькулятору балки — отдельный репозиторий на GitHub,
Render.com (Web Service, build: `pip install -r requirements.txt`,
start подхватывается из `Procfile`), затем карточка в `projects/`
портфолио со ссылкой на полученный адрес.

## Что можно расширить дальше
- нагрузки на сами стержни (не только в узлах) — потребует учёта
  местного изгиба, это уже не чисто ферма;
- разные сечения/материалы для разных стержней (сейчас — одно сечение
  на все стержни, как чаще всего и задают в учебных расчётах);
- 3D фермы (пространственные) — сейчас только плоские.
