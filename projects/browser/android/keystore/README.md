# Тестовый ключ подписи

`pitbrowser-test.keystore` — **открытый тестовый ключ** (пароль `android`, alias `androiddebugkey`).
Им подписаны тестовые сборки PitBrowser, чтобы новые версии ставились поверх старых без удаления
приложения (и без потери закладок и рекордов) — в любой сессии и в GitHub Actions.

Ключ лежит в открытом репозитории, поэтому **не годится для публикации** в Google Play или магазине:
перед публикацией создайте свой ключ и храните его только у себя / в секретах GitHub
(см. `projects/browser/README.md`). Приложение, подписанное другим ключом, придётся один раз
переустановить.
