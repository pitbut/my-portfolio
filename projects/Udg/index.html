Информация

Нарезание резьбы требует установки сменной гитары для получения требуемого шага резьбы. Передаточное отношение определяется отношением шагов.

Формулы для разных типов резьбы:

Метрическая: i = P / t
Дюймовая: i = (25.4 / P) / (25.4 / t)
Модульная: i = (π × m) / t
