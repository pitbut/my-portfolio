# 🌾 Агро-калькулятор

Flask-модуль: расчёт кормления сельхоз-животных и расчёт посева/удобрений.
Без базы данных и регистрации — как `balka`/`rashet-ferm`: заполнил форму,
получил результат на экране и `.docx`-отчёт.

## Корм для животных (`app.py: /api/feed/*`)

Животные: дойная корова, КРС на откорме/молодняк, свиноматки (супоросная/
подсосная), свинья на откорме, овцематка, овца/молодняк на откорме, коза,
курица-несушка, бройлер, кролик (`norms.py: ANIMALS`).

Расчёт идёт через энергетическую кормовую единицу (ЭКЕ): суточная
потребность = норма на поддержание (от живой массы) + норма на продукцию
(удой/привес/яйценоскость), затем раскладывается на виды корма по типовой
структуре рациона для двух режимов — стойловый (зима) и пастбищный (лето).

Три режима расчёта (`feed_calc.py`):
- **Прямой** — по поголовью и продуктивности → сколько корма нужно в сутки/за период.
- **Обратный по бюджету** — по имеющемуся объёму корма → сколько голов можно прокормить.
- **Обратный по цели** — по желаемому суммарному результату (например, «хочу
  1000 л молока за месяц») → сколько голов и корма нужно.

## Посев и удобрения (`app.py: /api/crop/*`)

Культуры: пшеница озимая/яровая, ячмень, овёс, рожь, кукуруза на зерно/силос,
подсолнечник, соя, рапс, картофель, сахарная свёкла (`norms.py: CROPS`).

Прямой расчёт (площадь → семена/удобрения/вода/трудозатраты/ожидаемый сбор)
и обратный (желаемый сбор → нужная площадь). Удобрения считаются по выносу
N/P₂O₅/K₂О с урожаем и переводятся в кг товарного продукта по выбранной
марке удобрения (`FERTILIZERS`). Если указана дата посева — считается
календарь созревания (типовой диапазон дней от посева до уборки). Если
заполнить цены (продукция/семена/удобрения/вода/труд) — считается экономика
(выручка/затраты/прибыль).

## Важно про точность норм

Все коэффициенты — типовые ориентировочные значения (структура норм
кормления по ЭКЕ, нормы высева, вынос питательных веществ) из общепринятых
зоотехнических/агрономических справочников. Реальные хозяйства отличаются по
породе/сорту, зоне, погоде и качеству кормов/почвы — калькулятор не заменяет
консультацию зоотехника/агронома для конкретного хозяйства. Коэффициенты
открыты (`norms.py`) и выводятся в результатах, чтобы их можно было
проверить и скорректировать под свои условия.

## Локальный запуск

```bash
pip install -r requirements.txt
python app.py   # http://localhost:5060
```
