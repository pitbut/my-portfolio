# Расчёт балки (сопромат) — модуль для сайта

Веб-модуль для расчёта прямой балки постоянного сечения на изгиб:
до 4 опор (шарнир-неподвижный, шарнир-подвижный, жёсткая заделка),
сосредоточенные силы и моменты, равномерные/линейные распределённые
нагрузки. Считает статически ОПРЕДЕЛИМЫЕ и НЕОПРЕДЕЛИМЫЕ балки
одним и тем же методом (МКЭ / метод перемещений), строит эпюры
Q(x), M(x), прогибов v(x) и формирует расчётно-пояснительную записку
в .docx с заданием, ходом решения, формулами по участкам,
подстановкой чисел, рисунками эпюр, проверкой прочности и жёсткости.

## Файлы
- `beam_engine.py` — ядро: МКЭ-решатель (балочный элемент Эйлера-Бернулли),
  аналитические Q(x)/M(x) по участкам, прогибы.
- `sections.py` — геометрические характеристики сечений (прямоугольник,
  круг, труба, короб, двутавр).
- `diagrams.py` — рисунки (matplotlib): расчётная схема, эпюры.
- `report.py` — сборка .docx записки (python-docx).
- `app.py` — Flask: `/` (интерфейс), `/api/calculate`, `/api/report`.
- `templates/index.html`, `static/style.css`, `static/app.js` — интерфейс
  конструктора балки (canvas-схема, формы ввода, результаты).
- `demo.py` — автономный пример без Flask (для проверки движка).

## Запуск локально
```
pip install -r requirements.txt
python app.py
```
Открыть http://127.0.0.1:5050

## Встраивание в существующий Flask-сайт
Скопировать `beam_engine.py`, `sections.py`, `diagrams.py`, `report.py`
в проект, зарегистрировать роуты из `app.py` как blueprint, подключить
`templates/index.html` и файлы из `static/`.

## Как проверялся расчёт
`beam_engine.py` протестирован на эталонных случаях сопромата:
- шарнирная балка с силой в центре → M_max = PL/4 ✓
- шарнирная балка с равномерной нагрузкой → M_max = qL²/8 ✓
- консоль (заделка) с силой на конце → M(заделка) = −P·L ✓
- неразрезная балка на 3 опорах, равномерная нагрузка →
  классические табличные реакции (3/8, 10/8, 3/8)·qL ✓

## Что можно расширить дальше
- треугольная (не только трапециевидная) эпюра распределённой нагрузки — уже
  поддерживается через q₁≠q₂;
- сохранение/загрузка расчётной схемы (JSON);
- таблицы сортаментов ГОСТ для двутавров/швеллеров вместо ручного ввода
  размеров;
- многопролётные балки с внутренними шарнирами (сейчас все узлы жёстко
  связаны по повороту между собой, кроме опор).
