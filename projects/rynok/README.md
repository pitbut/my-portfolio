# Рынок — семейный список покупок

Android-приложение для RuStore: жена составляет список покупок (голосом или
текстом, при желании с ценами), список мгновенно уходит мужу. Он отмечает,
что купил, и по какой цене; если руки заняты — спрашивает голосом «что
осталось» и приложение проговаривает ответ; кнопка «Итоговый бюджет»
озвучивает перерасход или экономию. Списки сохраняются в архив, есть
статистика расходов по неделям/месяцам и чат (текст, голосовые и видео
сообщения) прямо во время похода за покупками.

Так как приложением пользуется много разных семей одновременно, пары
находят друг друга по общему коду семьи (6 цифр): один телефон создаёт
список и получает код, второй вводит его.

## Структура

```
projects/rynok/
├── android/   — Android-приложение (Kotlin + Jetpack Compose)
├── server/    — сервер-релей (Node.js + WebSocket), связывает два телефона
└── index.html — витрина проекта для портфолио
```

## Архитектура и ключевые решения

- **Без Google Play Services.** RuStore ориентирован на устройства, часто без
  GMS, поэтому вместо Firebase используется собственный лёгкий сервер-релей
  (`server/`) на WebSocket. Он создаёт код семьи, соединяет два телефона и
  передаёт события (список, отметки о покупках, чат) в реальном времени.
- **История — только локально.** Сервер не хранит переписку и списки
  подолгу — он лишь передаёт сообщение получателю (или недолго буферизует
  его, если тот офлайн). Вся история хранится в Room-базе на каждом
  телефоне отдельно; если пользователь чистит кэш приложения — пропадает
  история только у него. Это осознанное решение по итогам обсуждения с
  заказчиком, а не недоработка.
- **Видео- и голосовые сообщения в чате**, а не звонки в реальном времени —
  запись и отправка коротких роликов (как в мессенджерах), а не WebRTC-звонки.
  Живые видеозвонки — это отдельная инфраструктура (STUN/TURN сервер),
  которая кратно увеличивает объём работы; при необходимости добавляется
  отдельным этапом.
- **Голос.** Ввод товаров и голосовая команда «что осталось» — через
  `android.speech.SpeechRecognizer`; ответы приложения — через
  `android.speech.tts.TextToSpeech`. Разбор фразы («молоко два литра по
  восемьдесят рублей») — простая эвристика (`voice/VoiceItemParser.kt`), не
  полноценный NLU: пользователь всегда может поправить результат вручную.

## Запуск сервера

```bash
cd projects/rynok/server
npm install
npm start        # слушает на порту 3000 (или $PORT)
```

Проверить: `curl http://localhost:3000/health`.

Для продакшена сервер можно развернуть так же, как остальные сервисы
портфолио — на Render (см. `render.yaml` в корне репозитория). За реальным
трафиком между двумя случайными телефонами по 3G/4G нужен HTTPS/WSS —
поставьте сервер за домен с TLS (например, тот же Render это делает
автоматически).

## Сборка Android-приложения

1. Установите [Android Studio](https://developer.android.com/studio).
2. Откройте папку `projects/rynok/android` как проект.
3. Укажите адрес вашего сервера-релея при сборке:
   ```
   ./gradlew assembleDebug -PrelayWsUrl=wss://ваш-сервер/ws -PrelayHttpUrl=https://ваш-сервер
   ```
   Без параметров используется адрес для локальной отладки на эмуляторе
   (`10.0.2.2` — алиас хост-машины из Android-эмулятора).
4. Запустите на эмуляторе или физическом устройстве (Run ▶ в Android Studio).

Gradle wrapper уже включён (`./gradlew`), Android SDK ставится через сам
Android Studio при первом открытии проекта.

## Публикация в RuStore

Это отдельный шаг, не автоматизируемый из репозитория:

1. Зарегистрируйте аккаунт разработчика в [RuStore Console](https://console.rustore.ru/).
2. Соберите подписанный релизный APK/AAB (`./gradlew bundleRelease`) —
   потребуется создать свой keystore для подписи (`android/app/build.gradle.kts`
   пока собирает debug-подписанные сборки).
3. Загрузите сборку в консоль RuStore, заполните карточку приложения и
   отправьте на модерацию.
4. Опционально — подключите [RuStore Push SDK](https://www.rustore.ru/help/sdk/push-notifications/)
   для доставки уведомлений, когда приложение свёрнуто (сейчас соединение
   держится, пока приложение открыто на переднем плане).
