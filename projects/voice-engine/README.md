# Voice Engine

Отдельный сервис клонирования голоса: озвучивает текст через бесплатный
Google TTS (правильное произношение и ритм речи) и накладывает поверх
тембр одного из заранее сохранённых голосов (voice conversion). Не связан
с проектом ai-tutor — самостоятельный микросервис, который потом можно
подключить к любому сайту по HTTP.

## Как это устроено

```
текст --> gTTS (озвучка) --> OpenVoice tone-color converter --> итоговое аудио
                                        ^
                                        |
                          эмбеддинг тембра голоса
                          (посчитан один раз при
                           добавлении голоса админом)
```

- **gTTS** даёт корректное произношение и интонацию — это бесплатный Google
  Speech, тот самый "робот", о котором шла речь.
- **OpenVoice V2** (пакет `openvoice-cli`) — открытая модель переноса
  тембра голоса (voice conversion). Она не переозвучивает текст заново, а
  меняет "окраску" уже готовой аудиодорожки под нужный голос — ровно тот
  сценарий, который обсуждался.
- Работает **полностью на CPU**, без видеокарты. Модель не обучается
  заново под каждый голос — только считает эмбеддинг тембра (доли секунды)
  и один раз применяет его к аудио (несколько секунд на фразу).

Проверено вживую в этом окружении: извлечение эмбеддинга ≈1 сек,
конвертация тембра ≈3-4 сек на фразу из 5-6 секунд звучания, на обычном
CPU без GPU. Первый запуск сервиса дополнительно скачает чекпоинт модели
(~130 МБ) с HuggingFace — дальше он кэшируется локально.

## Разделение ролей (как вы просили)

- **Админ** (`/admin`, закрыт токеном) — загружает запись голоса (1-3
  минуты чистой речи), сервис считает профиль тембра и сохраняет его.
  Сама запись после этого не хранится — остаётся только математический
  профиль, из которого голос обратно не восстановить.
- **Посетитель сайта** (`/`, публичный API `/api/*`) — видит только список
  готовых голосов по именам и может ими что-то озвучить. Того, что голоса
  вообще как-то создаются/клонируются, в публичном API нет вообще —
  только `id` и `name`.

## Установка

```bash
cd projects/voice-engine
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
sudo apt-get install -y --no-install-recommends ffmpeg   # нужен pydub/librosa для чтения любых форматов аудио
```

## Запуск

```bash
export VOICE_ENGINE_ADMIN_TOKEN="придумайте-длинный-случайный-токен"
python run.py
```

Сервис поднимется на `http://localhost:5001`:
- `http://localhost:5001/` — публичная демо-страница (выбор голоса + озвучка)
- `http://localhost:5001/admin` — админка добавления голосов (спросит токен)

Без `VOICE_ENGINE_ADMIN_TOKEN` все `/api/admin/*` роуты отвечают `503` —
это осознанно, чтобы случайно не запустить админку без защиты.

## API

Публичное:
- `GET /api/voices` → `[{"id": "...", "name": "..."}]`
- `POST /api/speak` `{"text": "...", "voice_id": "..."}` → аудио (`audio/wav`)

Админское (требует заголовок `X-Admin-Token`):
- `GET /api/admin/voices` → список голосов с датой создания
- `POST /api/admin/voices` (multipart: `name`, `audio`) → создаёт голос
- `DELETE /api/admin/voices/<id>` → удаляет голос

## Настройки (переменные окружения)

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `VOICE_ENGINE_ADMIN_TOKEN` | пусто (админка выключена) | токен для `/api/admin/*` |
| `VOICE_ENGINE_TTS_LANG` | `ru` | язык базовой озвучки gTTS |
| `VOICE_ENGINE_TAU` | `0.3` | сила переноса тембра: ближе к 0 — сильнее клонирование, ближе к 1 — ближе к исходному голосу Google |
| `VOICE_ENGINE_MAX_TEXT_LENGTH` | `500` | лимит длины текста на один запрос (защита от злоупотреблений) |

## Честные ограничения — то, что нужно знать перед продакшеном

1. **Не настоящий, полноценный "клон" голоса, а перенос тембра.** Ритм,
   паузы и манера говорить остаются от Google TTS — переносится только
   окраска/высота/резонанс голоса. Для одноголосого "аватара" сайта этого
   обычно достаточно, для точной имитации конкретного человека — нет.
2. **Приемлемо, но не мгновенно.** На слабом CPU синтез одной фразы
   (Google TTS + конвертация) — это порядка 3-6 секунд. Для чат-бота с
   голосовыми репликами это нормально, для звонка в реальном времени — нет.
   Если понадобится быстрее — тот же код можно направить на GPU, просто
   поменяв `device='cpu'` на `device='cuda'` в `engine/converter.py`, либо
   вынести обработку на арендованный GPU-сервер.
3. **Согласие на голос.** Технически ничего не мешает загрузить чужую
   запись без разрешения — это зона этических и юридических рисков
   (мошенничество, дипфейки). Если голоса будут не только ваши —
   стоит на уровне продукта подтверждать, что запись принадлежит тому,
   кто её грузит.
4. **Лицензия OpenVoice.** Библиотека `openvoice-cli` использует чекпоинты
   MyShellAI/OpenVoice — перед коммерческим использованием стоит свериться
   с их лицензией (на момент написания — permissive, но проверяйте
   актуальные условия на странице проекта).
5. **Google TTS через gTTS — неофициальный клиент.** Это не официальное
   Google Cloud TTS API, а обёртка над публичным веб-эндпоинтом Google
   Translate. Он бесплатный и без ключей, но не имеет SLA — если Google
   изменит эндпоинт, `gTTS` может временно перестать работать. Для
   продакшена с гарантиями можно заменить `engine/base_tts.py` на
   официальный Google Cloud Text-to-Speech (нужен API-ключ и биллинг).
