# Тараканьи бега — Android

Нативное Android-приложение (Kotlin + Jetpack Compose): порода/окрас/имя
таракана, интерактивный зал тренировок (таракан реально ходит есть/тренируется,
тапом ставятся препятствия, драгом рядом с ним его можно подтолкнуть), выбор
трассы, полноэкранная гонка вдоль экрана с «живым» нелинейным бегом, реакция
на громкий звук (микрофон) и удар по столу (акселерометр) с адаптивным
порогом, Bluetooth-турнир (классический RFCOMM, звёздная топология через
хоста) до 6 игроков в двух режимах поля — общее поле на всех экранах
или сложенное поле (телефоны в ряд, у каждого свой участок трассы) —
плюс турнирный режим для компаний больше 6 человек: заезды идут один
за другим, очки за места складываются в общую таблицу.

Готовый APK для установки: [`dist/roach-race-debug.apk`](dist/roach-race-debug.apk)
(debug-подпись, ставится как обычный APK).

## Сборка из исходников

Нужны JDK 17+ и Android SDK (platform 34, build-tools 34.0.0).

```bash
echo "sdk.dir=/путь/к/Android/Sdk" > local.properties
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Известные ограничения

- Bluetooth-лобби на 3+ человек — новая механика, живьём обкатано только
  соединение вдвоём.
- Режим «сложить телефоны в одно большое поле» (у каждого свой участок
  трассы) не реализован — только общее поле, зеркалируемое на все экраны.
- Публикация в RuStore/Google Play — следующий шаг.
