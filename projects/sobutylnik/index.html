🥂 Собутыльник

Не с кем выпить? Виртуальный ИИ-собутыльник поддержит беседу голосом, скажет тост, пошутит, чокнётся и подпоёт — через один мультимодальный ИИ-API (Anthropic Claude).

FlaskSQLAlchemyFlask-Migrate Anthropic ClaudeSQLite → PostgreSQLWeb Speech APIpytest

Проект пока не задеплоен на живой сервер — ниже описание архитектуры и как запустить исходники локально.

Это не статичная страница, а полноценное серверное приложение (backend на Flask + база данных + вызовы ИИ-API), поэтому оно не может работать напрямую на GitHub Pages — здесь хостится только статика. Исходный код целиком лежит в этой папке репозитория: projects/sobutylnik/. 
cd projects/sobutylnik
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # укажите ANTHROPIC_API_KEY, ADMIN_PASSWORD
flask db upgrade
python seed.py
python run.py
и откройте http://localhost:5000. Подробности — в README.md этого проекта.

Что умеет модуль

Голосовая беседа с barge-in

Распознавание речи и озвучка ответа в браузере (Web Speech API) — можно перебить собеседника в любой момент.

Тост, шутка, чоканье, музыка

Собеседник может произнести тост, пошутить, «чокнуться» или предложить застольную песню.

Выбор личности и голоса

Несколько собеседников с разным характером и любой голос из доступных в браузере.

Распознавание обстановки

Фото стола/компании анализируется мультимодальной моделью и обыгрывается в реплике.

Регистрация с подтверждением email

До регистрации доступна короткая демо-беседа на главной странице; полноценное общение — после подтверждения почты.

Чат поддержки с админом

Текст и файлы/фото — вопросы по оплате и доступу напрямую администратору.

Админ-панель и предохранители расходов

Блокировка пользователей по одному или всех сразу, общий рубильник всего приложения, лимиты сообщений с возможностью полностью их отключить.

Архитектура

Application factory (create_app), блюпринты (auth, main, chat, support, admin), схема БД — миграциями Flask-Migrate/Alembic. ИИ-провайдер вынесен в универсальный слой app/providers/ (интерфейс + адаптер Anthropic Claude) — добавление другого провайдера не требует переписывания маршрутов.
