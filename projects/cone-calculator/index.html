Визуализация конуса

Основные формулы:
C = (D - d) / L — конусность
C = 2·tg(α/2) — конусность через угол
tg(α₁) = (D - d) / (2L) — угол уклона
α = 2·arctg((D - d) / (2L)) — угол конуса
⚠️ Обозначения:
D — диаметр левого (большого) торца
d — диаметр правого (малого) торца
L — длина конуса
C — конусность
α — угол конуса (полный)
α₁ — угол уклона (половинный)
