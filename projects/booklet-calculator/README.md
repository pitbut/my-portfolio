# 📖 Печать книгой и тетрадями

Калькулятор порядка страниц для печати документа как буклета (книгой) или как нескольких сшивных блоков (тетрадями), без сторонних сервисов и загрузки файлов — только количество страниц.

## Что делает

1. Пользователь вводит количество страниц документа.
2. Выбирает режим:
   - **Книгой** — все листы вкладываются друг в друга (один буклет).
   - **Тетрадями** — документ делится на несколько блоков по N страниц (по умолчанию 16), каждый блок печатается и складывается отдельно, затем блоки собираются по порядку и сшиваются по корешку — так делают более толстые книги.
3. Инструмент считает раскладку 2 страницы на лист (импозиция) по стандартной формуле буклета и выводит:
   - готовый порядок страниц **в строку** (для вставки в поле «Страницы»/Pages диалога печати — большинство программ печатают страницы именно в указанном порядке, а не по возрастанию) и **столбиком**;
   - разбивку по листам (лицо слева/справа, оборот слева/справа), с отметкой пустых страниц, если общее число страниц не кратно 4;
   - отдельные списки для ручной двусторонней печати (проход 1 / проход 2) с возможностью показать проход 2 в обратном порядке листов — для принтеров без автоматического дуплекса;
   - краткие рекомендации по настройкам принтера (альбомная ориентация, переворот по короткому краю и т.д.).

## Формула импозиции

Для блока из `N` страниц (кратно 4), лист `s` (1..N/4):

```
лицо, слева  = N - 2s + 2
лицо, справа = 2s - 1
оборот, слева  = 2s
оборот, справа = N - 2s + 1
```

Это стандартная раскладка saddle-stitch буклета, проверена на N=8/12/16/20 — совпадает с классическими примерами импозиции (например, для 16 страниц: 16,1,2,15,14,3,4,13,12,5,6,11,10,7,8,9).

## Технологии

Один статический HTML-файл, чистый JavaScript, без зависимостей и без сервера — весь расчёт выполняется в браузере.
