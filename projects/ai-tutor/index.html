🎓 ИИ-репетитор

Персональные занятия по школьной программе: объяснение темы на доске, практические задания и проверка решений по фото — через один мультимодальный ИИ-API (Anthropic Claude).

Бесплатный тариф хостинга «засыпает» без запросов — первое открытие может занять 30-60 секунд. Для занятия нужен настроенный ключ Anthropic API на сервере.

Ниже — как устроен проект и как запустить его исходники локально. Это не статичная страница, а полноценное серверное приложение (backend на Flask + база данных + вызовы ИИ-API), поэтому оно не может работать напрямую на GitHub Pages — здесь хостится только статика. Исходный код целиком лежит в этой папке репозитория: projects/ai-tutor/. 
cd projects/ai-tutor
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # укажите ANTHROPIC_API_KEY
flask db upgrade
python seed.py
python run.py
и откройте http://localhost:5000. Подробности — в README.md этого проекта.

Что умеет модуль

Программа по классу

Ученик выбирает предмет и класс — темы идут по порядку, от простого к сложному.

Аватар, озвучка и голосовой barge-in

Выбор аватара и голоса; можно включить микрофон и перебить объяснение вопросом в любой момент.

Доска: текст, формулы, диаграммы

LaTeX-формулы, пошаговые решения, диаграммы и графики функций — рендерятся синхронно с объяснением.

Задания и проверка по фото

Минимум 3 задания на тему; решения проверяются по шагам через vision-модель.

Эмоциональная адаптация

По поведенческим сигналам (ошибки, темп ответов) репетитор меняет подачу материала — без камеры.

Свободный режим

Разбор любой непонятной темы вне программы по той же схеме занятия.

Админ-панель

Управление предметами/классами/программами/темами и прогрессом учеников.

Архитектура

Приложение построено на паттерне application factory (create_app), разбито на блюпринты (auth, onboarding, main, lesson), схема БД управляется миграциями Flask-Migrate/Alembic, системный промпт репетитора и учебный движок вынесены в отдельные модули (app/prompts.py, app/lesson_engine.py) — переключение LLM-провайдера или доработка сценария занятия не требует переписывания маршрутов.
