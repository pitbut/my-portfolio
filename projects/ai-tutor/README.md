# 🎓 ИИ-репетитор

Flask-модуль «ИИ-репетитор»: персональные занятия по школьной программе с
объяснением темы, интерактивной доской, практическими заданиями и проверкой
решений по фото — всё через один мультимодальный ИИ-API (Anthropic Claude).

Реализация построена по ТЗ `Техническое задание — Модуль «ИИ-репетитор» для
сайта` и системным промптам из `ai-tutor-system-prompt.md` (Промпт А — ведение
занятия, Промпт Б — генерация программы, Промпт В — определение эмоции по
кадру). Текущая версия закрывает **MVP (9.1) + v2 (9.2) + бо́льшую часть v3
(9.3, кроме камеры — см. ниже)**:

- регистрация/профиль, выбор аватара и голоса, выбор предмета и класса;
- текстовый чат с ИИ-репетитором по системному промпту, озвучка реплик
  через Web Speech API с анимацией аватара;
- голосовой ввод с barge-in: можно включить микрофон и задать вопрос прямо
  во время объяснения — озвучка мгновенно прерывается, репетитор отвечает
  и продолжает с того места, где остановился (см. ниже);
- доска с текстом, формулами (LaTeX через KaTeX), пошаговыми решениями,
  диаграммами и графиками функций (canvas/SVG-рендер на клиенте);
- эмоциональное состояние ученика — по поведенческим сигналам (подряд
  идущие ошибки в заданиях, время бездействия, фразы вроде "не понял"),
  без камеры — передаётся в промпт как `emotion_state`;
- свободный режим — разбор произвольной темы вне программы;
- загрузка фото решения и проверка через ИИ с vision;
- программа тем — фиксированный список в БД (`data/topics.csv`), с панелью
  `/admin` для добавления предметов/классов/программ/тем и просмотра
  прогресса учеников (пароль — `ADMIN_PASSWORD`);
- назначение следующего занятия — поле даты/времени с проверкой интервала
  (по умолчанию не раньше чем через 3 часа).

**TTS/STT без отдельного API-ключа:** и озвучка, и распознавание речи
сделаны через браузерный Web Speech API, а не платный голосовой сервис —
ТЗ прямо допускает для TTS/STT отдельный провайдер (раздел 6), и для
портфолио-проекта нулевая стоимость и отсутствие лишнего ключа важнее
студийного качества голоса. Поддержка и набор голосов зависят от браузера
ученика; без Web Speech API репетитор просто работает текстом, ничего не
ломается.

**Эмоции по камере — единственное, что осталось из раздела 9.3.** Сам ТЗ
формулирует это как "камера — опционально позже" даже внутри этапа v3, а
поведенческая эвристика уже покрывает основной сценарий (frustrated/
confused/bored/tired/engaged) без затрат на лишние вызовы vision-API и без
вопросов согласия на видео. `app/ai_client.py:detect_emotion` (Промпт В)
уже реализован и готов к подключению, если камера понадобится позже.

## Архитектура

Application factory (`create_app`) + блюпринты (`auth`, `onboarding`,
`main`, `lesson`), SQLAlchemy-модели без SQLite-специфичных типов
(переключение на PostgreSQL — через `DATABASE_URL`), схема БД управляется
Flask-Migrate/Alembic.

- `app/prompts.py` — промпты из ai-tutor-system-prompt.md с подстановкой
  параметров занятия.
- `app/ai_client.py` — единый клиент Anthropic API: ведение занятия,
  генерация программы, определение эмоции (все три — разные вызовы одного
  и того же провайдера, раздел 6 ТЗ).
- `app/lesson_parser.py` — разбор ответа модели на блоки SPEECH/BOARD/STATE.
- `app/lesson_engine.py` — оркестрация цикла занятия и служебных эффектов
  (создание заданий, обновление прогресса, назначение следующего занятия).
- `app/avatars.py` — фиксированный набор аватаров (имя подставляется в
  промпт как `{avatar_name}`); голос хранится как имя голоса браузера
  (`User.voice_name`), выбор — на клиенте.
- `app/static/js/tts.js` — озвучка реплик и анимация аватара через Web
  Speech API.
- `app/static/js/board.js` — рендер `diagram`/`graph` на доске (canvas для
  графиков функций, узлы/связи для диаграмм); схема JSON для этих типов
  описана в самом системном промпте (`app/prompts.py`, раздел 4 Промпта А).
- `app/static/js/stt.js` — распознавание речи и barge-in: прерывает
  озвучку при первом звуке речи ученика, финальный текст отправляется как
  обычное сообщение — модель сама решает, вопрос это или нет (раздел 5
  Промпта А), фильтровать реплики на клиенте не нужно.
- `app/emotion.py` — эвристика `emotion_state` по поведенческим сигналам
  (без ИИ и без камеры), вызывается из `lesson_engine` перед каждым ходом.
- `app/routes/admin.py` — панель `/admin`: управление предметами/классами/
  программами/темами и просмотр прогресса учеников. Авторизация — общий
  пароль на сессию (`ADMIN_PASSWORD`), без отдельной роли в таблице users.

## Запуск локально

```bash
cd projects/ai-tutor
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # и укажите ANTHROPIC_API_KEY
flask db upgrade
python seed.py          # заполняет предметы/классы/программы из data/*.csv
python run.py
```

Откройте `http://localhost:5000`. Без `ANTHROPIC_API_KEY` регистрация,
выбор программы и личный кабинет работают, но начать занятие нельзя —
интерфейс покажет понятную ошибку вместо падения.

## Тесты

```bash
pytest
```

Тесты `lesson_engine`/`lesson_parser` не обращаются к реальному ИИ-API —
`send_lesson_turn` подменяется на канонические ответы в формате
SPEECH/BOARD/STATE, чтобы проверять оркестрацию (создание заданий,
обновление прогресса, проверку интервала между занятиями) детерминированно.

## Наполнение новой программы через ИИ (Промпт Б)

MVP использует фиксированный список тем (раздел 9.1 ТЗ), но сам Промпт Б
реализован и его можно применить офлайн перед деплоем:

```bash
python scripts/generate_program.py "Химия" "9 класс"
```
