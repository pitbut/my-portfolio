# VR Магазин — прототип (шаг 1-2 дорожной карты)

Каркас проекта: 2 тестовых магазина, 6 товаров-заглушек (примитивы вместо
реальных 3D-моделей), витрина в Three.js/WebXR-совместимом браузере,
виртуальный продавец (текст + браузерный TTS), отзывы, заказ с ручной
оплатой по номеру карты, приглашение друзей ссылкой, тестовая загрузка
товара продавцом.

## Локальный запуск (для разработки)

```bash
cd backend
pip install -r requirements.txt
python seed.py          # создаёт shop.db (SQLite) и заполняет 2 магазина товарами
python app.py            # http://localhost:5050
```

Открой http://localhost:5050 — увидишь 2 магазина (TechDom, Mebel Test).

## Деплой

Проект теперь живёт как часть монорепозитория `my-portfolio`
(`projects/vr-shop/`) и разворачивается на общем VPS — см. `DEPLOY.md`.
Кликни на магазин → 3D-витрина: клик по товару переносит его на стол
продавца, товар крутится, справа появляется панель с описанием, ценой,
кнопками "Отзывы" и "Купить".

## Кабинет продавца (тест закладки товара)

http://localhost:5050/seller — форма: выбрать магазин, название, цену,
описание и (опционально) загрузить свой .glb/.gltf файл. Если файл не
загружен — подставляется тестовая заглушка (куб), чтобы карточка не была
пустой. Загруженный товар сразу появляется в 3D-витрине выбранного магазина.

## Что уже работает (проверка концепции)

- 2 независимых магазина с своим набором товаров
- Витрина с ценниками (canvas-спрайты) над каждым товаром
- Клик по товару → перенос на стол продавца + вращение 360°
- Виртуальный продавец: текстовое описание + озвучка (Web Speech API)
- Отзывы отдельно на товар и на магазин
- Покупка: адрес доставки + геолокация (по кнопке, через браузерный API) →
  создание заказа → показ номера карты для перевода (демо-номер,
  для реального проекта нужно подключить эквайринг Payme/Click/Uzcard)
- Приглашение друзей: генерируется ссылка на тот же магазин (без
  синхронизации движения — как договорились для первой версии)
- Тестовая загрузка товара продавцом (с реальным файлом модели или без)

## Что ещё НЕ сделано (следующие шаги дорожной карты)

- Регистрация/логин, роли buyer/seller, личный кабинет с историей покупок
- Реальный продавец (видео/чат) как альтернатива виртуальному
- Общий каталог с поиском по всем магазинам сразу (сейчас только 2
  магазина видны через список на главной)
- Настоящая интеграция карты (Leaflet/OSM) вместо просто координат
- Полноценный мультиплеер с синхронизацией движения гостей

## Структура

```
backend/
  app.py                  — Flask-приложение, все API-роуты
  models.py                — SQLAlchemy-модели (User, Shop, Product, Order, Review, Invite)
  seed.py                   — наполняет БД 2 тестовыми магазинами
  generate_test_models.py  — генерирует 6 GLB-заглушек (куб, сфера, цилиндр, тор, конус, икосаэдр)
  static/models/            — сгенерированные тестовые модели
  static/css/style.css      — общий стиль
  static/js/scene.js        — Three.js сцена (витрина, стол, взаимодействие)
  templates/                — index.html (список магазинов), shop.html (3D-витрина), seller.html (загрузка товара)
  uploads/                  — сюда попадают файлы, загруженные продавцом через форму
```
