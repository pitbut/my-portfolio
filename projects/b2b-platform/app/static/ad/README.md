Загрузите сюда файл с названием `banner.jpg` (или `banner.png` / `banner.gif`) через
FileZilla, в эту же папку на сервере — картинка рекламного баннера автоматически
появится на главной странице вместо заглушки «Здесь может быть ваша реклама».

Рекомендуемые пропорции — примерно как альбомная открытка (например 800×450 или
1000×560), чтобы картинка красиво заполняла баннер без искажений. Если файлов с
разными расширениями несколько, используется первый найденный в таком порядке:
.jpg, .jpeg, .png, .gif.
