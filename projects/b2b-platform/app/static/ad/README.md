Баннер универсальный — подходит и видео, и картинка.

- **Видео**: загрузите файл `banner.mp4` через FileZilla в эту же папку на сервере.
  Проигрывается автоматически, без звука, по кругу (как обычный рекламный ролик).
- **Картинка**: если видео нет, загрузите `banner.jpg` (или `banner.png` / `banner.gif`).

Если оба файла загружены — приоритет у видео. Рекомендуемые пропорции — примерно
как альбомная открытка (например 800×450 или 1000×560), чтобы баннер красиво
заполнял место без искажений. Видео лучше делать короткое и лёгкое (до 15-20 МБ),
чтобы страница быстро грузилась.
