# Деплой на Render — пошагово

## 1. Создать Blueprint из репозитория

1. Зайди на [render.com](https://render.com) → New → **Blueprint**.
2. Подключи GitHub-репозиторий `pitbut/my-portfolio` (если ещё не подключён —
   Render попросит авторизовать доступ через GitHub).
3. Render найдёт `render.yaml` в корне репозитория и покажет список
   сервисов для создания: `istok`, **`b2b-platform-uz`** и базу
   `b2b-platform-db`.
4. Отметь `b2b-platform-uz` (и `b2b-platform-db` — она отметится
   автоматически, так как на неё ссылается сервис) и нажми **Apply**.

Render сам создаст бесплатный Postgres и подставит `DATABASE_URL` в сервис
— вручную копировать строку подключения не нужно (см. `fromDatabase` в
`render.yaml`).

## 2. Первый деплой

Render запустит `buildCommand` и `startCommand` из `render.yaml`:

```
pip install -r requirements.txt
flask db upgrade && python seed.py && gunicorn run:app --bind 0.0.0.0:$PORT --timeout 120
```

`flask db upgrade` применит все миграции на свежей БД, `seed.py` заполнит
справочники (регионы/города Узбекистана, оборудование, услуги, материалы,
тарифы подписки). Через пару минут сервис будет доступен по адресу вида
`https://b2b-platform-uz.onrender.com`.

Открой этот адрес — увидишь главную страницу с paywall-модалкой. Уже сейчас
(без единого доп. ключа) полностью работают: регистрация по email, paywall,
профили заказчика/исполнителя, заказы, автоподбор, аукцион ставок, карта,
отзывы, барахолка, вакансии/резюме. Письма подтверждения и Telegram —
только в логе/в личном кабинете, пока не подключены ключи ниже.

## 3. Создать администратора

В панели Render → сервис `b2b-platform-uz` → **Shell** (вкладка вверху):

```bash
flask create-admin owner@example.com supersecret123
```

Теперь можно зайти под этим email/паролем и открыть `/admin/disputes` и
`/admin/subscriptions`.

## 4. Подключить реальные письма (Resend)

1. Зарегистрируйся на [resend.com](https://resend.com) (бесплатный тариф).
2. Раздел **API Keys** → создать ключ.
3. В Render → сервис → **Environment** → добавь `RESEND_API_KEY` = этот
   ключ. Сохрани — сервис перезапустится сам.
4. Без верификации своего домена в Resend письма шлются с адреса
   `onboarding@resend.dev` — этого достаточно для старта. Если нужен свой
   домен в поле «От кого» — верифицируй домен в Resend и укажи его в
   переменной `MAIL_DEFAULT_SENDER`.

## 5. Подключить вход через Google

1. [Google Cloud Console](https://console.cloud.google.com) → создать
   проект (или использовать существующий) → **APIs & Services** →
   **Credentials** → **Create Credentials** → **OAuth client ID**.
2. Тип приложения — **Web application**.
3. **Authorized redirect URIs** — добавь:
   `https://b2b-platform-uz.onrender.com/auth/google/callback`
   (подставь свой реальный адрес сервиса).
4. Скопируй `Client ID` и `Client Secret`.
5. В Render → Environment добавь `GOOGLE_CLIENT_ID` и
   `GOOGLE_CLIENT_SECRET`.

Кнопка «Войти через Google» появится на сайте сама — она скрыта, пока эти
переменные пустые.

## 6. Подключить загрузку фото (ImgBB)

1. [imgbb.com](https://imgbb.com) → зарегистрируйся → раздел **API** →
   скопируй ключ.
2. В Render → Environment добавь `IMGBB_API_KEY`.

Без этого ключа формы заказов/объявлений/доказательств в спорах
сохраняются без фото — сама загрузка просто отключена, ничего не падает.

## 7. Подключить Telegram-бота

1. В Telegram напиши [@BotFather](https://t.me/BotFather) → `/newbot` →
   придумай имя и юзернейм (должен заканчиваться на `bot`, например
   `b2b_uz_platform_bot`).
2. BotFather пришлёт токен вида `123456:ABC-DEF...` — это
   `TELEGRAM_BOT_TOKEN`.
3. В Render → Environment добавь:
   - `TELEGRAM_BOT_TOKEN` = токен от BotFather
   - `TELEGRAM_BOT_USERNAME` = юзернейм бота **без** `@`
   - `TELEGRAM_WEBHOOK_SECRET` = произвольная случайная строка (придумай
     сам, например `openssl rand -hex 16` в терминале)
4. После того как сервис перезапустится с новыми переменными, подключи
   вебхук (один раз, из терминала на своём компьютере):

```bash
curl -F "url=https://b2b-platform-uz.onrender.com/telegram/webhook/<TELEGRAM_WEBHOOK_SECRET>" \
     "https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook"
```

(подставь свой реальный адрес сервиса, свой секрет и свой токен).

5. Проверка: в личном кабинете сайта зайди в **Настройки** → «Подключить
   Telegram» → откроется бот → нажми Start. Придёт сообщение о привязке,
   и с этого момента уведомления о заказах/ставках/спорах будут приходить
   и в Telegram тоже.

## 8. Payme / Click / Uzcard (пока не подключено)

Для реального приёма оплаты подписки нужен мерчант-аккаунт в одной из
систем — это отдельная процедура регистрации бизнеса на их стороне, вне
компетенции этого чек-листа. До тех пор заявки на платный тариф
обрабатываются вручную в `/admin/subscriptions` (кнопка «Активировать»).

## Проверка, что всё работает

- Зарегистрируй тестового заказчика и исполнителя (два разных email).
- У исполнителя заполни профиль полностью (тип, локация, станочный парк,
  техвозможности) — должен включиться автоматический пробный период
  подписки.
- От заказчика опубликуй заказ той же категории услуг — исполнитель
  должен увидеть его в «Ленте заказов» и получить уведомление.
- Подай ставку, выбери победителя, заверши заказ, оставь отзывы с обеих
  сторон — все статусы должны меняться, второй отзыв должен опубликовать
  оба сразу.
