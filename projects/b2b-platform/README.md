# B2B Platform UZ — модуль 1 и 3 (регистрация, paywall, профили)

Рабочее Flask-приложение — первая реально работающая часть платформы, описанной
в техническом задании (`projects/b2b-equipment-platform-uz`). Реализовано:

- **Модуль 1** — регистрация по email (с подтверждением почты) и через Google
  OAuth, вход/выход, «жёсткий» paywall на уровне бэкенда (не только UI).
- **Модуль 3** — самостоятельное заполнение профиля заказчиком и исполнителем:
  локация с выбором точки на карте (Leaflet/OSM), для исполнителя — станочный
  парк, допустимые габариты/вес, категории услуг и материалы.
- Многоязычный интерфейс: русский / узбекская латиница / узбекская кириллица.

Ещё не реализовано (следующие этапы, см. ТЗ): публикация заказов и
автоподбор, аукцион ставок, барахолка, вакансии/резюме, Telegram-бот,
подписки и платежи, отзывы, арбитраж.

## Запуск локально

```bash
cd projects/b2b-platform
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # и при желании отредактируйте

flask db init          # один раз
flask db migrate -m "initial"
flask db upgrade
python seed.py          # заполняет регионы/города/справочники оборудования

python run.py            # http://localhost:5000
```

## Тесты

```bash
pytest
```

## Переменные окружения, которые нужно предоставить для полноценного продакшена

Всё это работает и без них (см. `.env.example` — комментарии объясняют
запасное поведение), но для реального продакшена понадобится:

- `SECRET_KEY` — случайная строка.
- `DATABASE_URL` — PostgreSQL (на Render создаётся отдельно, здесь только
  указывается ссылка).
- `RESEND_API_KEY` — чтобы письма подтверждения email реально отправлялись
  (иначе ссылка подтверждения просто показывается на сайте — это нормально
  для разработки, но не для реальных пользователей).
- `GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET` — чтобы заработала кнопка
  «Войти через Google» (OAuth-клиент создаётся в Google Cloud Console;
  Authorized redirect URI = `https://<домен>/auth/google/callback`). Без
  этих переменных кнопка Google просто не показывается — регистрация по
  email работает в полном объёме.
