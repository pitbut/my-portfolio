# Карточка «Герои Игр 3D» для RuStore

Всё, что нужно загрузить в [консоль разработчика RuStore](https://console.rustore.ru). Поля перечислены в том порядке, в каком они идут в консоли.

## 1. Файл приложения

| Поле | Значение |
|---|---|
| Файл | `../geroi-igr-3d.apk` (подписан релизным ключом) |
| Пакет | `com.robutpit.geroiigr` |
| Версия | 1.0 (versionCode 1) |
| minSdk / targetSdk | 24 (Android 7.0) / 35 |
| Ключ подписи | `geroi-igr-release.jks`, alias `geroi`. Ключ хранится у владельца и **не лежит в репозитории** |

Каждое обновление нужно подписывать тем же ключом и увеличивать `versionCode` в `android/app/build.gradle`.

## 2. Информация о приложении

| Поле | Ограничение RuStore | Что вставить |
|---|---|---|
| Тип | игра / приложение | **Игра** |
| Название | до 30 символов | `texts/01-nazvanie.txt` — «Герои Игр 3D» (12) |
| Основная категория | — | **Для детей** |
| Дополнительная категория | — | **Аркады** (или «Семейные») |
| Возрастной рейтинг | 0+ / 6+ / 12+ / 16+ / 18+ | **6+**: мультяшные зомби и лёгкое «насилие» (удар отталкивает) |
| Поисковые теги | до 5, из списка RuStore | детские игры, 3D, аркада, приключения, футбол (берите ближайшие из списка) |
| Краткое описание | до 80 символов, без эмодзи | `texts/02-kratkoe-opisanie.txt` (77) |
| Полное описание | до 4000 символов, на русском; самое важное в первых 2000 | `texts/03-polnoe-opisanie.txt` (2091) |
| Что нового | — | `texts/04-chto-novogo.txt` |

## 3. Графика

| Поле | Требование RuStore | Файл |
|---|---|---|
| Иконка | 512×512, PNG/JPG, без прозрачности, до 1 МБ; совпадает с иконкой в APK | `icon-512.png` (512×512, PNG без альфа-канала, 136 КБ) |
| Скриншоты для телефона | не меньше 3, 16:9 или 9:16, PNG/JPG, до 3 МБ, реальный интерфейс, без элементов Android | `screenshots/01…10` — 10 штук, 1920×1080 (16:9, горизонтальные), 130–350 КБ |

Загружайте скриншоты по порядку номеров: первые три лучше всего показывают игру (выбор героя → стройка → паук-герой). Ориентацию выберите **горизонтальную**.

## 4. Безопасность данных и разрешения

- **Сбор данных:** приложение не собирает и не передаёт никакие данные. Прогресс хранится только на устройстве.
- **Разрешения:** только `VIBRATE` (обычное, не «чувствительное»). Интернет не запрашивается.
- **Реклама / покупки:** нет. Приложение бесплатное, отмечать «Платное» не нужно.
- **Политика конфиденциальности:** `https://www.robutpit.com/projects/geroi-igr/privacy.html` (страница заработает, когда эта ветка попадёт в `main` и обновится сайт).

## 5. Контакты разработчика

Нужно заполнить хотя бы одно поле: email, группу ВК или сайт. Сайт: `https://www.robutpit.com`.

## 6. Комментарий для модератора (по желанию)

> Офлайн-игра на собственном 3D-движке (Three.js внутри WebView, все файлы внутри APK, интернет не нужен). Регистрации и тестового аккаунта нет. Названия миров и персонажи придуманы для игры и не используют чужие товарные знаки.
