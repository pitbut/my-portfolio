# Герои Игр 3D

3D-игра для Android (RuStore) и браузера. Пять героев — **Давид** (самый высокий), **Мухамад**, **Марк**, **Мустафо** и **Новичок** (своё имя) — проходят 9 миров по 3 уровня с прокачкой.

| Мир | Как играть |
|---|---|
| 🧱 Стройка на время | Собирай детали нужного цвета и неси на площадку, пока идёт таймер. Робот-пылесос выбивает детали из рук. |
| 🚦 Тише едешь | «Тише едешь — дальше будешь»: бежать можно только на зелёный свет. |
| 🧟 Зомби-апокалипсис | Собери канистры, отбивайся ударом 👊, улетай на вертолёте. |
| 🙈 Прятки | Ищи друзей в укрытиях 🔍, пустое укрытие стоит −3 сек. |
| 🏃 Догоняшки | Салки-замри: заморозь всех. На трудном уровне друзья выручают замерших. |
| 👾 Космический предатель | Задания 🔧 на корабле, предатель гонится, вентиляция, выключение света. |
| 🕷 Паук-герой | Прыжки по крышам, полёт на паутине 🕸, поимка злодея. |
| 🌋 Пол — это лава! | Паркур по мебели, тонущие подушки, катающиеся скейты. |
| ⚽ Футбол | Дриблинг, удар, вратарь и защитники. |

**Прокачка:** монеты → улучшения (скорость, прыжок, выносливость, жизни, магнит, сила); опыт → уровень героя (рост характеристик, кепка на 3-м уровне, корона на 8-м). До 3 звёзд за уровень. Сохранение — локально на устройстве.

## Структура

```
game/       — сама игра (HTML + JS + Three.js r158, работает офлайн)
android/    — Android-проект (WebView), берёт игру из ../game
rustore/    — всё для карточки RuStore: тексты, иконка, скриншоты, инструкция
geroi-igr-3d.apk — готовый подписанный APK
```

## Сборка APK

Нужны JDK 17+, Android SDK (platform 35, build-tools 35) и Gradle 8.9+.

```bash
cd android
echo "sdk.dir=/путь/к/android-sdk" > local.properties
# для подписанного релиза — keystore.properties (НЕ коммитить):
#   storeFile=/путь/к/geroi-igr-release.jks
#   storePassword=...
#   keyAlias=geroi
#   keyPassword=...
gradle assembleRelease
# → app/build/outputs/apk/release/app-release.apk
```

Для каждой новой версии увеличьте `versionCode` (и `versionName`) в `android/app/build.gradle`.

## Публикация в RuStore

1. Зарегистрируйтесь в [консоли разработчика RuStore](https://console.rustore.ru) (как физлицо/самозанятый/ИП/юрлицо).
2. «Создать приложение» → загрузите `geroi-igr-3d.apk`.
3. Заполните карточку по шагам из [`rustore/README.md`](rustore/README.md): там готовые тексты, иконка, 10 скриншотов, категория, рейтинг 6+ и ссылка на [политику конфиденциальности](privacy.html).
5. Отправьте на модерацию.

⚠️ Храните ключ подписи (`.jks`) и пароль: обновления в RuStore принимаются только с той же подписью.
