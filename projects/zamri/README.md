# 🪆 Замри! — кукла-судья для игры «Свет-стоп»

Android-приложение (Kotlin + Jetpack Compose), превращающее телефон в
полностью автономного судью для дворовой игры «Свет-стоп» (в духе «Красный
свет, зелёный свет»): кукла на экране поворачивается спиной/лицом к игрокам,
командует голосом, а фронтальная камера следит за игроками во время
красного света и ловит движение.

Все звуки, голосовые фразы и образ куклы — оригинальные, разработанные для
этого проекта; материалы из фильмов/сериалов не используются.

## 🎮 Игровой процесс

1. **Стартовый экран** — крупная кнопка «Начать игру», настройки и архив
   нарушений.
2. **Отсчёт 3‑2‑1** — время отойти от телефона.
3. **Зелёный свет** — кукла отвёрнута, движение разрешено. Длительность
   фазы случайна (по умолчанию 3–8 сек), чтобы момент смены нельзя было
   предсказать. Детектор движения в это время выключен для экономии
   батареи.
4. **Красный свет** — кукла поворачивается, звучит голосовая команда
   («Красный свет! Не двигаться!»), включается детектор движения на
   заданное число секунд.
5. **Нарушение** — если в каком-то секторе кадра зафиксировано движение
   выше порога:
   - делается снимок кадра в момент нарушения;
   - на снимке зачёркивается область движения (bounding box + красный крест);
   - снимок сохраняется в `Pictures/DollGame` (галерея устройства) и в
     локальную базу данных приложения;
   - голосом объявляется положение нарушителя относительно кадра —
     «Слева, второй!», «Справа, первый!», «По центру!»;
   - на экране на 2–3 секунды появляется оверлей с фото и подписью сектора.
6. Зелёная/красная фазы чередуются, пока не истечёт общий таймер игры или
   игрок не нажмёт «Финиш».
7. **Финиш** — озвучивается окончание игры, показывается статистика
   (раунды, число нарушений).
8. **Архив нарушений** — отдельный экран-галерея всех сохранённых снимков
   с фильтром по раунду, для разбора спорных моментов.

## 🧠 Компьютерное зрение

Детектор движения построен на **CameraX** (`ImageAnalysis` use case) без
тяжёлых ML-моделей:

- покадровое дифференцирование (frame differencing) в оттенках серого
  Y-плоскости YUV_420_888;
- пороговая бинаризация разницы кадров (порог зависит от чувствительности
  из настроек);
- лёгкая морфология erode → dilate (3×3) для подавления шума камеры;
- кадр делится на настраиваемое число вертикальных секторов (по умолчанию
  5); для каждого сектора считается доля «изменившихся» пикселей —
  превышение порога считается нарушением;
- детектор активен только во время красной фазы.

Модуль детекции — `motion/MotionDetector.kt`, конвертация YUV→Bitmap и
отрисовка отметки нарушения — `motion/ImageUtils.kt`.

## 🔊 Звук и голос

- **TextToSpeech** озвучивает положение нарушителя динамически, генерируя
  фразу по стороне и номеру сектора («Слева, третий!») без необходимости
  записывать клип на каждый сектор отдельно.
- Короткие оригинальные звуковые сигналы старта/стопа фаз (`res/raw/`)
  проигрываются через `SoundPool` по `STREAM_MUSIC` — без задержки TTS в
  критический момент смены фазы.
- Громкость регулируется в настройках и применяется к `STREAM_MUSIC`.

## 🏗️ Архитектура

- **MVVM**: `GameViewModel` (машина состояний `Idle → Countdown → Green ↔
  Red → Result`, `StateFlow`) + `ArchiveViewModel` для галереи.
- **Данные**: Room (`data/db/`) хранит метаданные нарушений (раунд,
  сектор, сторона, таймштамп, ссылка на фото); сами снимки — в
  `MediaStore` (`Pictures/DollGame`), видны в системной галерее.
- **Настройки**: DataStore Preferences (`data/SettingsStore.kt`) —
  длительность игры, диапазон зелёного света, длительность
  неподвижности на красном, число секторов, звук, громкость,
  чувствительность детектора.
- **UI**: Jetpack Compose, экран куклы анимирован через `Canvas` +
  `graphicsLayer(rotationY = …)` (эффект разворота на 180°).
- Экран держится включённым (`FLAG_KEEP_SCREEN_ON`) на протяжении игры.

## ⬇️ Установка APK

1. Откройте вкладку **Actions** → **Build Zamri APK** в этом репозитории,
   либо страницу **Releases** — там лежит собранный APK
   (`zamri-release-apk`), подписанный debug-ключом.
2. Скачайте `.apk` на Android-устройство.
3. При открытии файла разрешите установку из неизвестных источников для
   приложения, которым вы его открыли (браузер/файловый менеджер).
4. Установите и запустите — при первом запуске приложение запросит
   разрешение на камеру.

Сборка триггерится автоматически при push в `main` (если изменения
затрагивают `projects/zamri/**`) и при пуше тега вида `zamri-v*` — в этом
случае APK также прикладывается к GitHub Release.

## 🔐 Разрешения

| Разрешение | Зачем |
|---|---|
| `CAMERA` | обязательно — детектор движения смотрит на игроков через фронтальную камеру |
| `RECORD_AUDIO` | зарезервировано под будущий анализ звука (шум/аплодисменты), сейчас не используется активно |
| `WRITE_EXTERNAL_STORAGE` (только Android 9 и ниже, `maxSdkVersion=28`) | сохранение снимков в галерею на старых версиях Android; на Android 10+ используется `MediaStore` без дополнительного разрешения |

## 🛠️ Технические требования

- Kotlin, Jetpack Compose, `minSdk = 36`, `targetSdk = 36`
- CameraX, Room, DataStore Preferences, TextToSpeech
- Опционально подключён ML Kit Pose Detection как задел под более «умное»
  распознавание людей поверх базового детектора движения
