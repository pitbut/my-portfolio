💧 Открыть живой сайт →

Бесплатный тариф хостинга «засыпает» без запросов — первое открытие может занять 30-60 секунд.

Ниже — как устроен проект и как запустить его исходники локально. Это не статичная страница, а полноценное серверное приложение (backend на Flask + база данных), поэтому оно не может работать напрямую на GitHub Pages — здесь хостится только статика. Исходный код проекта целиком лежит в этой папке репозитория: projects/istok/. Чтобы посмотреть портал вживую, запустите его локально: 
cd projects/istok
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
flask db upgrade
python seed.py
python run.py
и откройте http://localhost:5000. Подробности — в README.md этого проекта.

Архитектура

Приложение построено на паттерне application factory (create_app), разбито на блюпринты по разделам (main, sacred, catalog, articles, library), схема БД управляется миграциями Flask-Migrate/Alembic с первого коммита, а модели не используют SQLite-специфичных типов — переключение на PostgreSQL через переменную окружения DATABASE_URL не требует переписывания кода.
